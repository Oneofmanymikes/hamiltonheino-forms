Canvass shifts

Creates shift slots for every day in the range — weekdays 1–3 PM and 5–7 PM, weekends also 10 AM–12 PM. Re-running only adds days that do not exist yet; it never changes or removes existing shifts.

Call list

Pulls new people from the form tabs and the Master List into CallList, the one tab the phone bank runs on. Adds only people it has not seen — existing call history is never touched. Run it after a batch of new signups or a fresh voter-file import.

Self sign-up

Set a shared access code and volunteers can create their own accounts — no admin needed. Leave it blank to close sign-up.
